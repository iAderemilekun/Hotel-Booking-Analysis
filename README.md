
# Hotel Booking Analysis Dashboard

## Project Overview
This project involves the analysis of hotel booking data using Microsoft Excel. The objective is to evaluate booking performance, profitability, revenue growth, customer demographics, room profitability, and country-level performance.

## Dashboard Preview

![Hotel Booking Dashboard](IMG_4393-preview.jpeg)

## Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Total Bookings Paid | $12.5M |
| Total Profits | $2.1M |
| Number of Bookings | 66,535 |
| Average Age | 38 |

## Dashboard Analysis

### 1. Yearly Revenue and Profit Growth
Analysis of yearly revenue and profit performance from 2010 to 2019, including year-over-year growth.

### 2. Total Profits by Age Group
Examination of profit distribution across different customer age groups.

### 3. Profit on Room per Gender
Comparison of room profitability between male and female customers.

### 4. Top Countries by Profits
Analysis of hotel booking profits across the countries represented in the dataset.

## Interactive Dashboard Filters
- Year
- Gender
- Origin Country
- Room Name

## Tools and Techniques
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Analysis
- Data Visualisation

## Key Insights
- Total bookings paid amounted to $12.5 million.
- Total profits reached $2.1 million.
- The dataset recorded 66,535 bookings.
- The average customer age was 38.
- Thailand recorded the highest profit among the countries displayed, at $391K.
